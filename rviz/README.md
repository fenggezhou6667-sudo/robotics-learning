# RViz Configuration

This project uses the official TurtleBot3 Navigation2 RViz configuration.

Launch:

ros2 launch turtlebot3_navigation2 navigation2.launch.py \
map:=/home/qingzhou/robotics-learning/maps/my_map.yaml \
use_sim_time:=True

The default RViz file comes from:

/opt/ros/humble/share/turtlebot3_navigation2/rviz/tb3_navigation2.rviz
